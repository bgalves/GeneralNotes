Tailscale Setup

- Linux install 

curl -fsSL https://tailscale.com/install.sh | sh

- start up Tailscale on linux terinal.
    - Note: We need to create a tskey-auth here every 90 days -> https://login.tailscale.com/admin/settings/keys

tailscale up --authkey=tskey-auth-xxxxxxxxxxxxx-1kkkkkkkkkkkkkET


- Setup Tailscale linux machine as exit node (this way all traffic will be redirected into this linux machine)
    - After all these commands bellow we need to go to admin console page and to vpnserver-alves activate and allow exit note action.

echo 'net.ipv4.ip_forward = 1' | sudo tee -a /etc/sysctl.d/99-tailscale.conf
echo 'net.ipv6.conf.all.forwarding = 1' | sudo tee -a /etc/sysctl.d/99-tailscale.conf
sudo sysctl -p /etc/sysctl.d/99-tailscale.conf
sudo tailscale set --advertise-exit-node --exit-node-allow-lan-access=true --advertise-routes=192.168.1.0/24 --accept-routes
